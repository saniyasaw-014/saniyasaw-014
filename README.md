**about**

I build at the intersection of AI and accessibility — things that make technology legible to people it usually ignores. My flagship project is a real-time navigation assistant for visually impaired users, combining object detection, scene description, and voice output on mobile. I care about systems that adapt to humans, not the other way around.

Outside code: I run a self-produced podcast distributed across Spotify, Amazon Music, and more — audience in 16+ countries, zero co-hosts, all from scratch.
